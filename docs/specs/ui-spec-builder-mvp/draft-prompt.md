# 영역 초안 프롬프트

앱이 화면에 표시하고 [프롬프트 복사]로 복사해 주는 지시문입니다. 아래 코드 블록 안의 내용이 그대로 사용자에게 보입니다. 실제 알림 카드 시험에서 지시를 넣었을 때 형식이 지켜진 응답을 바탕으로 다듬었습니다.

## 초안 요청 프롬프트

````text
첨부한 UI 스크린샷의 영역 구조를 분석해서, 아래 형식의 JSON만 응답해 주세요.
설명, 인사말, 주석은 쓰지 마세요. 코드 블록(```json) 하나로 감싸는 것은 괜찮습니다.

[JSON 형식]
루트 노드는 하나이고, 화면 전체를 뜻합니다 (id "screen", bounds [0, 0, 1, 1]).
모든 노드는 다음 필드를 가집니다.
- "id": 영문 소문자와 밑줄로 만든 이름. 전체에서 중복되면 안 됩니다. (예: notification_card)
- "type": "frame", "text", "shape", "icon" 중 하나만 씁니다. 다른 값은 쓰지 마세요.
- "bounds": [x, y, w, h] 숫자 4개.
  - x, y는 노드 왼쪽 위 모서리, w, h는 폭과 높이입니다.
  - 모두 이미지 전체 폭과 높이에 대한 0 이상 1 이하 비율입니다. 픽셀 값은 쓰지 마세요.
  - 소수점 넷째 자리까지 쓰고, x+w와 y+h는 1을 넘으면 안 됩니다.
- "children": 자식 노드 배열. 자식이 없으면 이 필드를 생략합니다.
- "text": type이 "text"인 노드에만 씁니다. 화면에 보이는 문구를 그대로 적고, 줄바꿈은 \n으로 씁니다.
  {{NN}}처럼 자리 표시자로 보이는 문구도 그대로 적습니다.

[노드 종류 규칙]
1. frame: 다른 노드를 담는 영역입니다. 배경색이나 둥근 모서리가 있는 카드, 버튼, 썸네일 배경도 frame입니다.
2. text: 문구 덩어리 하나입니다. 여러 줄이어도 노드 하나로 쓰고, 항상 frame의 자식으로 둡니다.
   bounds는 글자가 실제로 차지하는 영역에 맞춥니다.
3. shape: 안에 아무것도 없는 단독 도형입니다. (예: 진행 바에서 채워진 부분, 구분선)
   내용을 담은 배경은 shape가 아니라 frame입니다.
4. icon: 아이콘이나 이미지입니다. (예: 앱 아이콘, 화살표, 썸네일 안의 그림)

[구조 규칙]
- 자식의 bounds는 부모의 bounds 안에 완전히 들어가야 합니다.
  여러 줄 텍스트는 부모 frame이 텍스트 전체를 감싸도록 잡습니다.
- 한 줄에 나란히 있는 항목은 같은 부모 frame으로 묶습니다. (예: 헤더의 아이콘, 이름, 시간)
- 자식은 위에서 아래로, 왼쪽에서 오른쪽 순서로 나열합니다.
- 색, 글꼴, 크기 같은 스타일 값은 쓰지 마세요.
- 화면에 보이는 모든 문구, 아이콘, 도형, 버튼을 빠짐없이 노드로 만듭니다. 큰 영역에서 시작해 문구 하나, 아이콘 하나 같은 가장 작은 요소까지 내려가세요.
- 화면에 보이지 않는 요소를 만들어 내지 마세요.

[형식 예시] (형식만 참고하세요. 구조, id, 노드 개수는 따라 하지 말고 스크린샷에 보이는 대로 만드세요)
{
  "id": "screen",
  "type": "frame",
  "bounds": [0, 0, 1, 1],
  "children": [
    {
      "id": "login_card",
      "type": "frame",
      "bounds": [0.1, 0.1, 0.8, 0.8],
      "children": [
        { "id": "login_title", "type": "text", "bounds": [0.15, 0.14, 0.3, 0.08], "text": "Sign in" },
        {
          "id": "email_field",
          "type": "frame",
          "bounds": [0.15, 0.3, 0.7, 0.15],
          "children": [
            { "id": "email_icon", "type": "icon", "bounds": [0.17, 0.33, 0.06, 0.09] },
            { "id": "email_placeholder", "type": "text", "bounds": [0.26, 0.35, 0.3, 0.05], "text": "Email" }
          ]
        },
        {
          "id": "submit_button",
          "type": "frame",
          "bounds": [0.15, 0.6, 0.7, 0.15],
          "children": [
            { "id": "submit_label", "type": "text", "bounds": [0.4, 0.64, 0.2, 0.07], "text": "Continue" }
          ]
        }
      ]
    }
  ]
}
````

## 수정 요청 문구 (오류가 있을 때)

앱이 검증 오류를 찾으면 틀린 항목을 채워 넣어 복사하게 해 주는 문구의 모양입니다.

````text
방금 응답에서 아래 문제가 있었습니다. 같은 형식을 유지한 채, 문제가 있는 부분만 고쳐서 JSON 전체를 다시 응답해 주세요.
설명은 쓰지 마세요.

- {노드 id 또는 위치}: {무엇이 틀렸는지. 예: bounds 값 1.2가 0～1 범위를 벗어났습니다}
- {다음 문제}

지켜야 할 규칙: type은 frame, text, shape, icon만 쓰고, bounds는 [x, y, w, h] 비율(0～1)이며, 자식은 부모 안에 있어야 하고, id는 중복되면 안 됩니다.
````
